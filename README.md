# C---- · 基于 ESP32-S3 的智能健康手环（课程实训）

80 学时 / 10 天课程设计项目：终端自治的运动与久坐提醒手环。核心闭环「察觉—提醒—反馈」——
连续 45 分钟无有效活动即震动提醒（2 s × 3），走 30 步复位；阈值写入 NVS 掉电保存。
判定、提醒与本地记录全部在 ESP32-S3 上完成，断网不影响必做功能。

## 本期范围

| 类别 | 内容 |
| --- | --- |
| 必做 (P0) | 计步、久坐判定与提醒、表盘、运动页面、设置、六页面交互、本地记录 |
| 选做 (原有) | 心率血氧、体温、跌倒检测、Wi-Fi 同步、PC 管理端（Qt 5） |
| 选做 (新增) | FR-19 PC 端大模型健康问答 / FR-20 基于 PC 归档数据的 RAG 检索 / FR-21 手环操控鼠标（BLE HID） |

选做均可整块裁剪，裁剪后不影响「提醒能触发 · 数据能显示 · 断电不丢设置 · 连续运行不死机」四条底线。
非医疗器械，所有健康数据仅保存在设备与教师机、不出公网；问答须附检索来源并标注非医疗建议。

## 技术栈

C++17 · ESP-IDF 5.x · FreeRTOS · LVGL 8.3 · CMake 3.16+；
PC 端 Qt 5.15 + SQLite + Qt Charts（选做）。
外设：MPU6050 (0x68) / MAX30102 (0x57) / TMP117 (0x48) / FT6236 (0x38) / 4.3" SPI 屏 / 震动马达。

## 协作规范

`main` 保持可运行，功能在 `feature/xxx` 分支开发、MR 合入前至少 1 人评审；
提交信息用「动词 + 对象 + 原因」，例如 `fix: 修复马达震动期间误计步的问题`。
详见 `health-band/docs/03_Git仓库与提交规范.md` 与 `health-band/CONTRIBUTING.md`。

## 本地运行 Demo

直接用浏览器打开 `demo/index.html`（无需服务器、无外部资源），
短按右侧按钮翻页、长按熄屏/回表盘；底部「选做扩展链路」区展示 FR-19/20/21。
