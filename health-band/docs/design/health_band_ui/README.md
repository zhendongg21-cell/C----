# 智能健康手环 UI 设计图包

基于所提供用户界面设计说明书第3至6节，提供三套完整主题。方案A深蓝青绿对齐说明书基线，方案B纯黑活力环，方案C浅色极简。三套共用功能与导航。

## 数量与格式

每套23张独立界面PNG和23张SVG；三套合计69张界面。另有5张关系/工作流程图，各提供PNG与SVG。overview含5张总览图。手环PNG原始尺寸800×480，PC界面1440×900。所有数值均为演示样例，不代表实测。

## 编号

UI-00为各L1视图中复用的状态栏和页点。UI-01表盘，02运动，03心率血氧，04体温，05久坐，06设置，07久坐提醒覆盖层，08系统确认，UI-PC-01管理端，02健康问答，03鼠标映射。完整图像唯一ID由方案字母和视图ID构成，见manifest.json。

UI-03/04状态S01结果、S02测量中、S03信号差、S04未佩戴、S05未启用。UI-06-S01/S02是同一设置页的上下滚动视口，不是新增页面。C01表示额外确认视图。

## 新增三项选做（与需求基线对齐）

本图包已包含三项 P2 加分选做的界面与流程，与 `health-band/docs/00_需求规格说明书.md`（v1.1）编号一致：

| 编号 | 选做功能 | 本图包落点 | 必守边界 |
| --- | --- | --- | --- |
| FR-19 | PC 端接入大模型询问健康情况 | UI-PC-02_PC健康问答（含 RAG 来源卡、免责声明）、03-04_PC问答工作流程 | 回答须附检索来源、标注「教学演示，非医疗建议」；模型与检索不出公网（NFR-11） |
| FR-20 | RAG 检索基于 PC 端已收集数据 | UI-PC-02 的「检索来源」区、UI-PC-01 归档视图 | 语料仅取 SQLite records / events 归档数据，按 (device_id, ts) 溯源；无数据时不编造（NFR-11） |
| FR-21 | 手环操控鼠标 | UI-PC-03_PC鼠标映射、UI-PC-03-C01_PC鼠标开启确认、03-05_PC鼠标工作流程 | 默认关闭、二次确认、PC 端一键断开、超时自动断开；不进入计步/久坐主流程（NFR-12） |

依赖链：FR-14/15（Wi-Fi 同步 + PC 端只读归档）→ FR-20（RAG 索引）→ FR-19（健康问答）；FR-21 为独立链路。三项均可整块裁剪，不影响「提醒能触发 / 数据能显示 / 断电不丢设置 / 连续运行不死机」四条底线。

## 使用方法

在Word中插入PNG即可使用；需要改字改色时使用SVG。SVG文字字体为Noto Sans SC，电脑未安装时可用思源黑体或微软雅黑替换；PNG不依赖字体。图形不是整屏位图实现建议，LVGL应复用标签/圆弧/卡片/图表等原生组件。配套Word提供每个界面的对象功能与操作说明。

## 共用交互

短按或页面背景右滑：01→02→03→04→05→06→01。长按2秒切换背光；5秒回表盘；10秒进入系统确认。长按按最终持续时间互斥判定。UI-07未处理前禁止切页和背景交互。图表内横向滑动只看历史；设置页纵向滑动只滚动内容。页点不可点击。

## 待确认

原说明书尚未明确稍后3次上限后的行为、步数目标编辑入口、估算个人参数、温度传感器稳定时间与最终HID手势。流程图明确保留未定项。PPG仅用于心率血氧，体温必须来自独立温度传感器。同步与鼠标映射默认关闭、开启确认。
